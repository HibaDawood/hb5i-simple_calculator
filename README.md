# 🧮 CLI Simple Calculator

A clean and efficient command-line calculator application built using TypeScript and Node.js. It prompts users to input two numeric values and select a basic arithmetic operation to execute real-time mathematical calculations.

---

## ✨ Features

* **Strict Numeric Input:** Enforces numeric values using `inquirer`'s native number type to prevent bad data entry.
* **Interactive Operations Menu:** Simple drop-down selection for standard arithmetic operators: Addition, Subtraction, Multiplication, and Division.
* **Robust Conditional Architecture:** Uses strict execution blocks to safely output calculated mathematical results.

---

## 🚀 How to Run & Use

1. Navigate to your calculator project folder in the terminal.
2. Install the `inquirer` package dependency:

   ```bash
   npm install inquirer

3. Compile and execute the application:

```bash
npx tsc && node index.js
